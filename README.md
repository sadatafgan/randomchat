# RandomChat - نسخه آزمایشی (فاز ۱: چت متنی)

## این پروژه چیست؟
یک نسخه اولیه و ساده از یک اپ چت رندوم (شبیه Omegle) که فعلاً فقط
**چت متنی** را پشتیبانی می‌کند. این فاز ۱ است — بعد از تست موفق،
ویدیو/صدا را در فاز بعدی اضافه می‌کنیم.

---

## مرحله ۱: نصب Node.js
اگر نصب نداری، از https://nodejs.org نسخه LTS را دانلود و نصب کن.

برای اطمینان، در ترمینال بنویس:
```
node -v
```
باید یک شماره نسخه نشان بدهد (مثلاً v20.x.x).

---

## مرحله ۲: اجرای بک‌اند (سرور)

در ترمینال:
```
cd backend
npm install
npm start
```

اگر همه‌چیز درست بود، باید این را ببینی:
```
🚀 سرور روی پورت 3001 در حال اجراست
```

این ترمینال را باز بگذار — این سرور باید همیشه در حال اجرا باشد.

---

## مرحله ۳: اجرای فرانت‌اند (رابط کاربری)

یک ترمینال **جدید** باز کن (ترمینال قبلی را نبند) و بنویس:
```
cd frontend
npm install
npm run dev
```

باید آدرسی شبیه این نشان بدهد:
```
Local:   http://localhost:5173/
```

این آدرس را در مرورگر باز کن.

---

## مرحله ۴: تست با دوستانت

### گزینه A - تست روی یک شبکه وای‌فای (ساده‌ترین حالت)
1. IP سیستم خودت را پیدا کن:
   - ویندوز: در cmd بنویس `ipconfig` و دنبال IPv4 بگرد (مثلاً 192.168.1.5)
   - مک/لینوکس: در ترمینال بنویس `ifconfig` یا `ip addr`
2. در فایل `frontend/vite.config.js`، به تنظیمات `server` این خط را اضافه کن:
   ```js
   server: {
     port: 5173,
     host: true,   // این خط را اضافه کن
   },
   ```
3. دوستت که در همان وای‌فای است، در مرورگر می‌رود به:
   `http://IP-تو:5173`

### گزینه B - تست از راه دور (دوستان در شهر/کشور دیگر)
این نیاز به دیپلوی روی اینترنت دارد (Render برای بک‌اند + Vercel برای فرانت‌اند).
این کار را در مرحله بعدی با هم انجام می‌دهیم — الان اول مطمئن شو نسخه لوکال کار می‌کند.

---

## اگر مشکلی پیش آمد

**مشکل: صفحه سفید یا "در حال اتصال..." گیر کرده**
→ مطمئن شو بک‌اند (مرحله ۲) واقعاً در حال اجراست و خطا نداده.

**مشکل: خطای CORS در کنسول مرورگر**
→ بک‌اند را ری‌استارت کن (Ctrl+C و دوباره `npm start`).

**مشکل: پورت 3001 یا 5173 اشغال است**
→ یک برنامه دیگر از آن پورت استفاده می‌کند. کافیست سیستم را دوباره راه‌اندازی کنی یا پورت را در کد عوض کنی.

---

## بعد از تست موفق، قدم بعدی چیست؟
وقتی این نسخه متنی بین چند دوست تست شد و مطمئن شدیم matching درست کار می‌کند،
فاز بعدی را شروع می‌کنیم: اضافه کردن ویدیو/صدا با WebRTC.
